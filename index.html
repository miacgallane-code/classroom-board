Which links work?
  • Google Slides – paste the normal link from the address bar. The deck needs to be shared as “Anyone with the link can view”, or you need to be signed in to Google in this browser.
  • Canva – Share → Public view link.
  • PowerPoint – in PowerPoint for the web: File → Share → Embed, then paste the embed code. Or save the deck as a PDF and upload it.
  • Anything else that gives you an embed code (an <iframe>) can be pasted too.
